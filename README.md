# Small Docker images

Four small nginx images. They need no database and no outside service.

| Image | What it serves | More |
|---|---|---|
| [`xinterx1512/steadfast`](https://hub.docker.com/r/xinterx1512/steadfast) | Free Bootstrap template | [KokybiskaSvetaine.lt](https://kokybiskasvetaine.lt/) |
| [`xinterx1512/vardadieniai`](https://hub.docker.com/r/xinterx1512/vardadieniai) | Lithuanian name days API | [Dovanos su vardu](https://dovanasuvardu.lt/vardadieniai/) |
| [`xinterx1512/vestuviu-metines`](https://hub.docker.com/r/xinterx1512/vestuviu-metines) | Wedding anniversary names API | [Vestuvių metinės](https://vestuviumetines.lt/) |
| [`xinterx1512/naujagimiu-vardai`](https://hub.docker.com/r/xinterx1512/naujagimiu-vardai) | Popular baby names API | [Krikštynų dovana](https://krikstynudovana.lt/) |

Each folder has its own Dockerfile and description.
